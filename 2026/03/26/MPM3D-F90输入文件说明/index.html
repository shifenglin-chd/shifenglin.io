前言

目的

  • 用于查询 MPM3D-F90 输入文件关键词

  • 作为后续新增关键词与使用说明的统一记录入口

  • quick index 和 detail message

关键词类型

输入关键词可按形式分为三类：

  • 开关型：无参数
    例如：smoo

  • 单参数型：一个参数
    例如：dtscale 0.8

  • 多参数型：多个参数
    例如：spx 0 10

说明方式

每一部分均尽量保持统一结构：

  1. 输入模板

  2. 输入示例

  3. 关键词表

  4. 必要备注

内部计算（Constitution.f90）

$$
q = \rho (a L^2 \dot{\varepsilon}_v^2 - b L c \dot{\varepsilon}_v)
$$

说明

  • a, b 为人工黏性系数

  • 用于抑制压缩过程中的数值振荡

5. 输出控制

输入模板

输入示例

关键词表

关键词 含义 备注
para 输出 ParaView 文件（.vtu） 开启后生成 .vtu + .pvd，用于 ParaView 可视化，默认输出粒子场变量（如位移、速度、应力等）。
tecp 输出 Tecplot 文件 生成 Tecplot 格式数据文件（通常为 .dat），用于 Tecplot 可视化，和 para 二选一或同时使用。
curv 时间历程曲线输出 定义某个粒子某个变量随时间变化的曲线（输出到文本文件）。
outr 动画/结果输出变量选择 定义哪些变量被写入 plot / animation 文件；代码中对应 AnimOption，如 pres、velx、damg 等。
curx 按坐标定义曲线输出点 与 curv 类似，但不是直接给粒子编号，而是输入空间坐标，由程序自动寻找最近粒子并输出其时程曲线。

10 velz pt%VXp(3)
12 fail pt%failure
14 damg pt%DMG
15 stre pt%SDxx + pt%SM
16 disx pt%Xp - pt%Xo
17 disy pt%Yp - pt%Yo

9. 初始条件

当前主要包含 荷载 和 速度

9.1 外力

输入模板

关键词表

关键词 含义 备注
load 外力定义模块开始 进入外力/重力设置区域，需与 endl 成对使用。
part 单个粒子外力 格式：part ip fx fy fz，对编号为 ip 的粒子施加外力分量。
body 整个体的统一外力或速度 在 load 模块中格式为 body ib fx fy fz；在 velo 模块中格式为 body ib vx vy vz。同一关键词在不同模块含义不同。
grav 重力加速度 格式：grav ib gx gy gz，对第 ib 个 body 施加重力加速度，而不是直接施加力。
endl 外力定义结束 结束 load 模块。

输入示例

9.2 初始速度

输入模板

关键词表

关键词 含义 备注
velo 初始速度定义模块开始 进入初始速度设置区域，需与 endv 成对使用。
body 整个体的统一外力或速度 在 load 模块中格式为 body ib fx fy fz；在 velo 模块中格式为 body ib vx vy vz。同一关键词在不同模块含义不同。
node 单个粒子初始速度 格式：node ip vx vy vz。虽然关键词叫 node，但代码中实际对应的是粒子编号。
ksin 正弦分布初始速度场 格式：ksin v0 ib，对指定 body 施加沿 x 方向的正弦型初始速度场，常用于波传播或振动 benchmark。
kbon 特定算例初始速度场 代码中对应 Euler beam 特殊测试用速度场，不属于通用输入选项。
endv 初始速度定义结束 结束 velo 模块。

10. 结束

输入模板

非常用关键词

本节主要是关于爆炸的关键词

关键词 含义 备注
deto 爆炸起爆点（detonation point） 用于读取起爆点坐标，通常为 x, y, z 三个分量。
QuLo 准静态加载（Quasi-static Loading） 外力准静态加载模块，输入加载时间后激活。
Damp 外力阻尼因子 准静态问题中使用的阻尼模块。
drda 动力松弛阻尼（dynamic relaxation damping） 用于静力/准静态求解的阻尼开关。
